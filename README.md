# 🥚 Pok Pok Web Clone

เว็บเกมแนว clicker ที่ได้แรงบันดาลใจจากเกม Pok Pok ใน Roblox

## ฟีเจอร์
- 🥚 แตะไข่เพื่อรับเหรียญ
- ⚡ ระบบพลังงาน (Energy)
- 🛒 ร้านค้าอัปเกรด (Click / Auto / Energy)
- 🏆 ระบบเลเวล
- 💾 Save/Load ด้วย localStorage

## วิธีรัน
เปิด `index.html` ในเบราว์เซอร์ได้เลย

## Deploy บน GitHub Pages
1. สร้าง repo ใหม่ชื่อ `pokpok-game`
2. อัปโหลดทั้ง 4 ไฟล์
3. ไปที่ **Settings → Pages**
4. เลือก Branch: `main`, folder: `/ (root)`
5. กด Save แล้วรอ 1-2 นาที
6. เข้าเล่นได้ที่ `https://<username>.github.io/pokpok-game/`

## เทคโนโลยี
- HTML5 / CSS3 / Vanilla JS
- ไม่ต้องใช้ Build tool หรือ dependency ใดๆ
